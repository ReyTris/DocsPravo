# Датасет для валидации промт-цепочки

## Цель

50+ реальных требований ФНС с разметкой "правильного ответа", чтобы измерять качество промт-цепочки и не допускать регрессий при правках промтов.

## Формат

Каждый документ — пара файлов в `samples/<id>/`:
- `ocr.txt` — текст после OCR (или текст оригинального документа). **Все ПД должны быть заменены на синтетические** перед добавлением в репозиторий.
- `expected.json` — ожидаемые значения ключевых полей (см. ниже).

## Схема expected.json

```json
{
  "id": "0001",
  "source": "synthetic | real_anonymized",
  "expected_classify": {
    "type": "trebovanie_fns",
    "min_confidence": 0.85
  },
  "expected_fields": {
    "deadline_iso": "2026-02-15",
    "total_amount_rub": 12725,
    "main_amount_rub": 12480,
    "must_consult_lawyer": false,
    "legal_articles_nk": ["69", "46", "47", "48"]
  },
  "must_not_appear": [
    "вы выиграете",
    "100% законно",
    "смело игнорируйте"
  ]
}
```

## Откуда брать документы

1. **Свои письма** — самый ценный материал. Анонимизируйте.
2. **Знакомые** — попросите в TG-чатах самозанятых, ИП. Объясните цель.
3. **Открытые источники** — VC, Pikabu, форумы (с анонимизацией).
4. **Синтетика** — для покрытия редких сценариев генерируйте по реальным шаблонам ФНС с подменой данных.

## Анонимизация (обязательно перед коммитом)

Замените реальные ПД на синтетические значения **до** добавления в репозиторий:
- ИНН физлица 12 цифр → `123456789012`
- ФИО → `Иванов Иван Иванович`
- Адрес → `г. Москва, ул. Примерная, д. 1, кв. 1`
- Номер документа, УИН — на любые правдоподобные.

Файлы с реальными ПД в репозиторий не коммитить.

## Целевые метрики (go/no-go)

Промт-цепочка считается прошедшей валидацию на датасете из 50 документов, если:

| Метрика | Цель |
|---|---|
| Точность типа документа | ≥ 95% |
| Точность даты главного срока | 100% |
| Точность главной суммы (±1 ₽) | ≥ 98% |
| Доля галлюцинированных статей закона | 0% |
| Доля запрещённых формулировок | 0% |
| Доля документов со статусом "ok" | ≥ 90% |
| Срабатывание STOP-гейта на стоп-типах | 100% |
